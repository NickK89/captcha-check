# 🕵️‍♂️ Автотест проверки капчи

Скрипт на Python с использованием Playwright для автоматического поиска капчи (видимой, невидимой и текстовой) на страницах сайтов. Сохраняет скриншоты найденных капч и выводит общий отчет.

## 🚀 Установка
1. Активируйте виртуальное окружение: `source .venv/bin/activate`
2. Установите зависимости: `pip install playwright`
3. Установите браузер: `python -m playwright install chromium`

## 📖 Как пользоваться
1. **Сбор ссылок:** Откройте файл `crawl.py`, укажите сайт в `START_URL` и запустите:
   `python crawl.py`
2. **Проверка капчи:** Запустите основной скрипт:
   `python check.py`
3. **Результаты:** Скриншоты сохраняются в папку `screenshots/`.

## 📁 Структура проекта
- `crawl.py` — краулер для сбора URL.
- `check.py` — чекер для поиска капчи.
- `.gitignore` — исключения для Git.
